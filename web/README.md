# Fetchlinks Web

This is the new Next.js TypeScript application scaffold for the Fetchlinks web UI. It lives beside the existing Flask app while the replacement is built and validated one step at a time.

## Runtime

The scaffold targets Node 18.18 or newer, including the Node 18 package available on Ubuntu 24.04.

## Commands

```bash
npm install
npm run dev
npm run lint
npm run build
```

The development server listens on http://localhost:3000 by default.
